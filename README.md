# muufi

A tiny Android reader with a **built-in, network-level ad blocker** (powered by
[`adblock-rust`](https://github.com/brave/adblock-rust), the engine behind Brave).
Fullscreen-free UI: native **top app bar** + **bottom navigation bar**, with the
Android **status bar** (clock / battery / camera cutout) and **navigation bar**
(back / home / recents) left visible.

- **Language:** Kotlin (native Android) + Rust (ad-blocking core)
- **Size budget:** ≤ 20 MB (single ABI, arm64-v8a, R8 release build)
- **Built in the cloud:** GitHub Actions compiles the Rust `.so` + APK, so nothing
  heavy runs on the phone.

## Ad blocker

- **Toggle:** About (the ⓘ button) → **Toggle ads** turns blocking on/off. The
  choice is remembered across launches.
- **Install popup:** on first launch the engine is built in the background and a
  toast reports **"Ad blocker: installed (N lists, M resources)"** or
  **"Ad blocker: INSTALL FAILED: …"** (same style as the GeckoView edition's
  "uBO: installed" toast). The About dialog shows the current status too.
- **Aggressive, Brave-style:** bundles Brave's own filter lists (first-party,
  cookie, social, Android) plus EasyList/EasyPrivacy, uBO filters/privacy/
  quick-fixes/unbreak/badware, AdGuard Base/Mobile/Tracking/Annoyances/URL
  tracking, Fanboy annoyance/social/cookie/newsletter/mobile and URLhaus.
- **`$redirect` + scriptlets:** Brave's resource bundle and uBlock Origin's
  `$redirect` resources are loaded (`tools/build-resources.mjs`), so redirect
  rules serve safe replacements (noop stubs, etc.) instead of breaking pages.
- **`$removeparam`:** tracking query parameters are stripped from top-level
  navigations (Brave's "aggressive" clean-URLs behaviour).

## How the ad blocker works

- Filter lists are bundled gzipped in `app/src/main/assets/filters/` (refresh
  with `tools/fetch-filters.sh`).
- On first launch they're decompressed into `filesDir/filters/` and compiled into
  an `adblock-rust` `Engine` (in a background thread).
- `WebViewClient.shouldInterceptRequest()` runs every subresource through the
  engine — blocked requests get an empty response (real network blocking), and
  `$redirect` matches serve their replacement body instead.
- `url_cosmetic_resources()` supplies element-hiding selectors + scriptlets, which
  are injected into each page.
- `shouldOverrideUrlLoading()` applies `$removeparam` clean-URL rewrites.

The compiled resource bundle (`assets/adblock/resources.json`) is generated by
`tools/build-resources.mjs` from Brave's published resources plus uBlock Origin's
`$redirect` resources.

## Launcher + source list (GitHub Pages)

The home screen is a static site hosted on **GitHub Pages**:

**https://mkaafi6.github.io/muufi/**

Edit `frontend/sites.json` (on github.com or locally) and push — the launcher
updates in ~30s with **no APK rebuild**. The app loads this URL as its home screen,
so changing links never requires a new APK.

Sources currently: BBC News, Reuters, AP News, NPR, Al Jazeera.

## Build / download

Push to `main` → GitHub Actions **Build Android APK** → download the
**`muufi-release-apk`** artifact and install it (enable "Install unknown apps").

## Layout

```
app/src/main/
  java/com/mkaafi6/muufi/  MainActivity.kt, AdBlocker.kt   (Kotlin + JNI)
  assets/filters/          gzipped filter lists
  assets/adblock/          resources.json (Brave + uBO $redirect resources)
  assets/offline.html      offline fallback page
  res/                     layout, theme, vector icons, launcher icon (TV)
frontend/                  launcher site (index.html + sites.json) → GitHub Pages
rust/adblock/              Rust cdylib (adblock-rust + JNI)
tools/                     fetch-filters.sh, build-resources.mjs
.github/workflows/         cloud APK build + Pages deploy
```

## Notes

- Cosmetic + network blocking, `$redirect` resources, and `$removeparam` clean
  URLs are enabled. uBO's newer `##+js(...)` scriptlet format is not converted
  yet, so those specific scriptlets are the main remaining gap.
- Release APK is signed with the Android **debug** key (installable; not store-ready).
- **Filter list licenses:** EasyList (GPLv3 / CC-BY-SA), uBlock Origin filters and
  resources (GPLv3), Brave lists and resources (MPL-2.0), AdGuard lists (GPLv3),
  Fanboy lists, Peter Lowe's list, URLhaus. See their upstream repos for terms.
